# Skin Disorder Prediction using Machine Learning

## Project Overview

This project focuses on predicting different **skin disorders** using **Machine Learning algorithms** based on clinical and histopathological features.

The objective of this project is to assist in early disease identification and improve medical decision-making through predictive analytics.

---

## Problem Statement

Skin disorders can be difficult to diagnose manually and may require expert medical evaluation. This project aims to build a predictive system that classifies skin diseases accurately using patient-related features.

---

## Dataset Information

The dataset contains:

- Clinical Features
- Histopathological Features
- Disease Categories

Data preprocessing techniques such as:

- Missing Value Handling
- Feature Scaling
- Data Cleaning
- Exploratory Data Analysis (EDA)

were applied before model training.
